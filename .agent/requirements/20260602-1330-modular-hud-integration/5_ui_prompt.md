# UI Prompt

Design the ONOKO ARCANA play screen as a dark, premium tarot instrument. The visual language is Astra Nocturne: obsidian black, antique gold lines, sapphire crystal accents, and precise occult geometry.

Use generated PNG components as modular ornament:

- panel corner caps and plaques at panel edges,
- compact pips for active/revealed state,
- card slot halos under cards,
- command button frames and rails,
- progress markers for reveal order.

Keep the table and cards readable. Do not cover the playfield with a fixed full-screen overlay. Text remains real HTML/UMG text, never baked into images.
