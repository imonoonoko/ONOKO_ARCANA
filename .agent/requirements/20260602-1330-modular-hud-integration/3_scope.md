# Scope

## In Scope

- Add project-local references to the generated modular HUD kit.
- Apply a small set of selected PNG parts to:
  - app side panels,
  - top spread plaque,
  - command buttons,
  - spread choices,
  - card slot states,
  - progress/status elements.
- Add generated asset existence checks to the lightweight Web app checker.
- Preserve all current reading behavior.
- Run static and rendered smoke verification.

## Out Of Scope

- Regenerating the entire HUD kit.
- Replacing all controls with image-only widgets.
- Moving labels or Japanese text into images.
- Adding new spread definitions.
- Packaging/distribution work.
- Unreal/UMG import for these HUD assets.
