# Purpose

## Goal

Make the current ONOKO ARCANA Web/Electron HUD feel more like a bespoke ONOKO oracle instrument by using the newly generated modular HUD elements as decorative, reusable UI layers.

## Target Users

- The project owner evaluating the finished play-screen direction.
- Future players who need a readable tarot table before any premium Unreal/3D layer is revisited.

## Success Criteria

- The screen reads less like a generic dark web app and more like ONOKO ARCANA.
- Cards, spread layout, note input, guide lock, and history remain readable.
- The generated HUD assets are used as modular pieces, not as a single full-screen overlay.
- The app still passes the static and smoke checks.
