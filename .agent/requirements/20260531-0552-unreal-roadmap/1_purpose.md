# ONOKO ARCANA Unreal Roadmap Purpose

## Problem
ONOKO ARCANAには、カンバン、カード表面、カード裏面、ONOKO参考画像、HTML一覧、確認レポートなど複数の成果物がすでに存在する。しかし、これらが「どの順番でPCソフトへ統合されるのか」「Unreal Engineで何を最初に検証するのか」「小アルカナや追加素材へ進む前に何を固定するのか」がまだ一枚の設計文書に統合されていない。

## Target User
- タロットカードを所持していなくても、PC上で占いを試したいユーザー。
- カードの意味を丸暗記ではなく、操作、比較、記録を通して学びたいユーザー。
- ONOKOの世界観を、占い卓、カード、ガイドUIとして体験したい制作者および利用者。

## Current Workaround
現在はHTMLレポートでカード一覧を確認し、デザインカンバンで方向性を読む形になっている。タロットの実操作、カードを引く演出、解釈メモ、履歴保存、学習導線はまだ統合アプリとして存在しない。

## Why Now
大アルカナ22枚の画像とJSON定義が揃い、カード比率問題も `2:3` に固定された。さらに今後は立体的なPCソフトを目指す方針が出ており、Unreal Engineへ移行する前に、素材群を研究ロードマップとして体系化する必要がある。

## Desired Outcome
ONOKO ARCANAの今後の制作判断が、次の基準で進められる状態にする。

- 既存素材が何で、どれが採用候補か分かる。
- Unreal Engine版で最初に作るべき縦断スライスが分かる。
- タロット学習、占い操作、ONOKOらしさ、3D演出の優先順位が分かる。
- 小アルカナや追加生成に進む前の品質ゲートが明確になる。

## Success Definition
- `docs/roadmap/ONOKO_ARCANA_UNREAL_RESEARCH_ROADMAP_2026-05-31.md` が、素材棚卸し、設計原則、技術方針、フェーズ計画、受け入れ基準、リスク、参照リンクを含む。
- `reports/onoko-arcana-unreal-roadmap-2026-05-31.html` がブラウザで開け、主要素材とロードマップを視覚的に確認できる。
- 次工程として「Unreal Engine縦断プロトタイプ」へ進める粒度の実装ブリーフが存在する。
