# Scope

## In Scope

- Review current Git status at a high level.
- Keep all current work intact.
- Verify referenced reports and roadmap files exist.
- Commit the current state on `main`.
- Push the commit to `origin/main`.
- Check that the overall roadmap reflects the current Web/Electron mainline.
- Record the push and roadmap completion evidence.

## Out Of Scope

- Force-push or history rewrite.
- Deleting generated reports or workflow artifacts.
- Changing GitHub repository settings.
- Creating a pull request unless explicitly requested later.
- New feature implementation beyond roadmap completion.
