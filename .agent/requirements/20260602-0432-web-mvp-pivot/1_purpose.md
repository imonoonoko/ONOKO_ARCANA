# Purpose

ONOKO ARCANA needs a path that reaches a playable divination table before the project spends more time fighting Unreal-specific lighting, map wiring, UMG setup, and editor automation. The purpose of this slice is to separate the product loop from the engine choice.

The MVP should prove that a player can:

- choose a spread,
- draw cards,
- reveal cards in order,
- select a card,
- write their own reading,
- compare against guidance,
- save the session,
- revisit past readings.

If that loop works as a rich 2D Web table, the project can continue toward a desktop app through Electron or Tauri with lower operational risk. Unreal remains valuable for later 3D staging, promotional scenes, or a premium build once the product shape is already proven.
