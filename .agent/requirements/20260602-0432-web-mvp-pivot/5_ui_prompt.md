# UI Prompt

Design ONOKO ARCANA as a dense cyber-oracle tarot table, not a marketing page. The first viewport is the working table.

Visual rules:

- Use near-black background, blue-black acrylic panels, restrained gold dividers, and electric blue active states.
- Keep the table and spread cards visually dominant.
- Use the generated ONOKO card images as the primary visual assets.
- Let panels feel like instruments around the table.
- Use compact Japanese labels and controls.
- Do not hide the cards behind large decorative overlays.
- Cards should appear luminous, readable, and physical enough even in 2D.

Interaction rules:

- Spread selection is visible and immediate.
- Draw creates the spread but keeps cards unrevealed.
- Reveal advances one card at a time.
- Selecting a card updates the interpretation panel.
- Writing notes and saving readings are part of the same screen.
- History is accessible without leaving the table.
