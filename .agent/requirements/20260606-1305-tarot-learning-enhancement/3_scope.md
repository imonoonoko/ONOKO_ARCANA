# Scope

## MVP Learning Scope

Add study features that reuse current data and history:

- Major Arcana study library.
- Card detail sheet with upright, reversed, keywords, study focus, symbol notes, and reflection prompts.
- Recall-first practice prompts.
- Card-specific history review.
- Study lens expansion from aggregate stats to actionable review.

## Phase 2 Learning Scope

Add durable learning state:

- Per-card mastery status.
- Spaced review queue.
- Quiz attempts and confidence ratings.
- Mistake log for confused cards.
- "Compare my note to guide" view.

## Phase 3 Learning Scope

Add deeper tarot literacy:

- Spread tutor.
- Story synthesis training.
- Symbolism/numerology/history modules.
- Minor Arcana readiness gate.

## Out Of Scope For This Roadmap

- AI-generated predictive readings as the primary value.
- Account-based cloud learning sync.
- Paid course marketplace.
- Medical, legal, or financial advice framing.
