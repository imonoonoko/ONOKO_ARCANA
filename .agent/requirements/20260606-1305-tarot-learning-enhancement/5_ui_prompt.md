# UI Direction

## Visual Intent

The learning layer should feel like ONOKO's study notebook attached to the cyber divination table, not like a separate course dashboard.

## Surfaces

- Right panel: compact Study Lens and card-specific review entry.
- Modal or drawer: Card Study Sheet.
- Table mode: Practice Mode overlays recall prompts on the card before guide reveal.
- Future tab/panel: Study Library, only after the core reading table remains stable.

## UI Copy Principles

- Use "観測", "復習", "自分の読み", "照合", "次の学習候補".
- Avoid "正解" for interpretive answers. Use "照合", "近い観点", "別視点".
- Reversals should not be framed only as bad outcomes. Use blocked, delayed, internalized, excessive, or reversed expression.

## First Slice UI

Add "カード別復習" from Study Lens:

- Frequent card row can be clicked.
- Clicking opens all saved readings containing that card.
- The card detail includes the user's notes, guide keywords, and study focus.
