# ONOKO ARCANA v0.1.0 Distribution Notice

This notice is intended for the GitHub Release zip and the generated local Electron package.

## Package Type

ONOKO ARCANA v0.1.0 is distributed as an unsigned local Electron folder package.

It is not a signed Windows installer, does not include auto update, and does not collect or sync user data through a server.

## Local Data

Readings, notes, and learning state are stored locally by the app.

Use the in-app export and import features to back up or migrate history. Do not publish exported history JSON if it contains private questions, notes, or reading records.
